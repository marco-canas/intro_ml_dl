






# *Curso: Introducción al lenguaje Python para formar en ciencia de datos con técnicas de Machine Learning y Deep Learning*

**Programa:** Administración de Empresas
**Duración sugerida:** 4 a 5 semanas (módulo introductorio dentro de la línea de analítica de datos)

---

# **UNIDAD 1. Pensamiento computacional y fundamentos del lenguaje Python**

**Propósito:** Comprender el papel del pensamiento computacional en la administración moderna y familiarizarse con la lógica y sintaxis básica de Python.

**Conceptos clave:**

1. Ciencia de datos y transformación digital en la gestión empresarial
2. Pensamiento computacional y resolución de problemas
3. Entorno de trabajo con Python (Anaconda, Google Colab, Jupyter Notebook)
4. Sintaxis básica de Python:

   * Tipos de datos (numéricos, texto, booleanos)
   * Variables y expresiones
   * Operadores aritméticos y lógicos
   * Estructuras de control (`if`, `for`, `while`)
5. Funciones y modularidad
6. Entrada y salida de datos
7. Comentarios, buenas prácticas y legibilidad del código

**Producto de aprendizaje:**
Primer script en Python que calcule indicadores financieros básicos (margen de ganancia, punto de equilibrio).

---

# **UNIDAD 2. Python para el análisis y la visualización de datos**

**Propósito:** Aplicar Python para la manipulación, organización y visualización de información relevante para la toma de decisiones empresariales.

**Conceptos clave:**

1. Introducción a la biblioteca **NumPy**: arreglos, operaciones y estadísticas básicas
2. **Pandas** para el manejo de datos tabulares:

   * Series y DataFrames
   * Carga de datos desde CSV, Excel o web
   * Limpieza y transformación de datos
   * Cálculo de indicadores y métricas de negocio
3. **Visualización de datos**:

   * Gráficos con Matplotlib y Plotly
   * Gráficos de barras, líneas, dispersión y pastel
   * Dashboards básicos y visual storytelling

**Producto de aprendizaje:**
Cuaderno Jupyter con análisis descriptivo y visualización de indicadores de ventas o rentabilidad.

---

# **UNIDAD 3. Introducción al aprendizaje automático (Machine Learning)**

**Propósito:** Comprender los fundamentos del aprendizaje automático y aplicarlos a casos empresariales simples.

**Conceptos clave:**

1. Concepto de *Machine Learning* y su relación con la analítica predictiva
2. Tipos de aprendizaje: supervisado, no supervisado y por refuerzo
3. Flujo de trabajo de un modelo de ML:

   * Recolección y preparación de datos
   * División en entrenamiento y prueba
   * Entrenamiento del modelo
   * Evaluación y ajuste de precisión
4. Modelos básicos con **scikit-learn**:

   * Regresión lineal (predicción de ventas o costos)
   * Clasificación (segmentación de clientes o predicción de morosidad)
5. Interpretación de resultados para la toma de decisiones empresariales

**Producto de aprendizaje:**
Modelo de regresión lineal aplicado a datos de inversión publicitaria y ventas con análisis de correlación.

---

# **UNIDAD 4. Introducción al Deep Learning y redes neuronales**

**Propósito:** Conocer los principios básicos del Deep Learning y su aplicación al análisis de datos empresariales más complejos.

**Conceptos clave:**

1. Diferencias entre Machine Learning y Deep Learning
2. Concepto de neurona artificial y red neuronal
3. Arquitectura de una red neuronal simple
4. Uso básico de **TensorFlow** y **Keras**:

   * Definición de capas
   * Compilación y entrenamiento
   * Evaluación del modelo
5. Aplicaciones en gestión empresarial:

   * Predicción de satisfacción del cliente
   * Clasificación de comentarios o reseñas
   * Modelos de riesgo crediticio

**Producto de aprendizaje:**
Modelo de red neuronal simple para clasificar clientes o predecir satisfacción.

---

# **UNIDAD 5. Proyecto integrador: Ciencia de datos aplicada a la administración**

**Propósito:** Integrar los conocimientos del curso en un proyecto aplicado a la realidad empresarial.

**Conceptos clave:**

1. Ciclo de vida de un proyecto de ciencia de datos
2. Selección y descripción de un problema empresarial
3. Limpieza, análisis y modelado de datos
4. Presentación de resultados en formato Jupyter Notebook
5. Comunicación de hallazgos mediante video explicativo

**Producto de aprendizaje final:**
Proyecto completo publicado en GitHub y video explicativo en YouTube:

> *“Aplicación de ciencia de datos y aprendizaje automático a la toma de decisiones empresariales.”*

# **Secuencia conceptual transversal**

| Eje conceptual                 | Conceptos nucleares                    | Conexión con la administración                       |
| ------------------------------ | -------------------------------------- | ---------------------------------------------------- |
| **Pensamiento computacional**  | Algoritmo, variable, bucle, función    | Automatización de procesos empresariales             |
| **Estructura de datos**        | Listas, arreglos, DataFrames           | Representación de información contable o de clientes |
| **Análisis descriptivo**       | Promedios, desviaciones, correlaciones | Inteligencia de negocios (BI)                        |
| **Aprendizaje automático**     | Modelo, entrenamiento, predicción      | Predicción de ventas, segmentación de mercado        |
| **Deep Learning**              | Neuronas, capas, redes                 | Análisis de textos, satisfacción del cliente         |
| **Comunicación de resultados** | Visualización, interpretación, reporte | Presentación ejecutiva de hallazgos basados en datos |
